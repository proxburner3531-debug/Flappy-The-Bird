## Gameplay

Guide the bird through gaps between pipes while avoiding collisions. Try to achieve the highest score possible!

## Controls

- **Mouse Click** — Make the bird flap.
- **Spacebar** — Make the bird flap.

## Features

- Bird movement and flap mechanics
- Pipe spawning and obstacle movement
- Score tracking
- Collision detection and game-over system
- Main menu and game scene

## Technologies Used

- Unity
- C#

## About the Project

An independently developed project created to practise C# programming, Unity fundamentals, game mechanics, and scene management.
